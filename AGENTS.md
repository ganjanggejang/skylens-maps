# Agent instructions

After completing implementation changes with `/mod` files,
use the `build-and-test-mod` skill to verify the changes at
[.agents/skills/build-and-test-mod/SKILL.md](.agents/skills/build-and-test-mod/SKILL.md).

Before starting implementation changes under `/src`, read and use the
`build-and-test-src` skill at
[.agents/skills/build-and-test-src/SKILL.md](.agents/skills/build-and-test-src/SKILL.md)
throughout implementation and final browser verification.
